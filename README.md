# ImamKhomeiniMod — Forge 1.20.1

Initial functional mob implementation: peaceful wandering humanoid, custom pixel texture, and spawn egg.

Build with Java 17 and Forge 1.20.1 (47.2.0). GitHub Actions builds the JAR.

Spawn command: `/summon imamkhomeinimod:imam`
Spawn egg: `imamkhomeinimod:imam_spawn_egg`

This is an initial stylized pixel texture, not a photorealistic likeness. Test in-game before treating the JAR as verified.
