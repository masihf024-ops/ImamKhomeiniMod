# ImamKhomeiniMod

Minecraft Forge 1.20.1 project starter.

## Build
This project uses Java 17 and Forge 1.20.1 (47.2.0).
GitHub Actions builds the mod automatically when code is pushed.

**Current status:** starter project only. The custom 3D character model, textures, guards, residence, and interactions still need to be implemented and tested.
